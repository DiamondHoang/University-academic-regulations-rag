# HCMUT Academic Regulations Chatbot

This is an intelligent AI assistant designed to help students and faculty at **Ho Chi Minh City University of Technology (HCMUT)** navigate academic regulations.
Experience it now at: [https://huggingface.co/spaces/diphoenix/regulationchatbot](https://huggingface.co/spaces/diphoenix/regulationchatbot)

### Key Features
- **Context-Aware Chat**: Supports follow-up questions for a natural conversation experience.
- **Fact-Based Answers**: Provides accurate information directly sourced from official university documents.
- **Smart Citations**: Every response includes citations for transparency and verification.
- **Automatic Recency**: Prioritizes the latest issued regulations to ensure you receive the most up-to-date information.

### Technology Stack
Built using a modern RAG (Retrieval-Augmented Generation) pipeline featuring **BGE-M3** embeddings, and **ChromaDB** for efficient semantic search.
